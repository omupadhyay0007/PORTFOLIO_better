4. Technical Projects

Project 1: Perplexity Explorer Live Demo ↗
HTML CSS JavaScript Transformers.js DistilGPT-2 Vercel
Repository & Docs:
github.com/omupadhyay0007/perplexity-explorer and the deployed application.
Problem Statement:
Perplexity is a language-model metric that is difficult to interpret without seeing token probabilities and intermediate calculations. The project presents those calculations through an interactive educational interface.
Solution Architecture:
A browser application loads DistilGPT-2 through Transformers.js, tokenizes user text, runs causal-language-model inference, and displays token probabilities and perplexity calculations.
Tech Stack:
HTML, CSS, JavaScript, Transformers.js, Xenova/distilgpt2, browser-hosted tensors, and Vercel hosting.
Individual Contribution:
Sole developer. Built and deployed the interface, integrated browser-based model inference, and implemented the perplexity calculations and explanatory views.
Project 2: LLM Pipeline Explorer Live Demo ↗
HTML5 CSS3 Vanilla JavaScript BPE WordPiece Canvas Vercel
Repository & Docs:
github.com/omupadhyay0007/llm-pipeline-explorer (repository configured as private) and the public live application.
Problem Statement:
Large-language-model text processing is difficult to visualize because tokenization, vocabulary IDs, semantic relationships, and custom vocabulary changes happen in separate internal stages.
Solution Architecture:
A client-side HTML application processes text using selectable BPE, WordPiece, and whitespace tokenizers. It synchronizes token chips, token statistics, vocabulary tables, custom tokens, and a native Canvas-based 3D semantic embedding view.
Tech Stack:
HTML5, CSS3, vanilla JavaScript, Byte-Pair Encoding, WordPiece, Canvas rendering, semantic similarity calculations, and Vercel hosting.
Individual Contribution:
Sole developer. Built the interactive tokenizer interface, 3D semantic visualization, custom vocabulary workflow, synchronized data views, and deployed the application.
